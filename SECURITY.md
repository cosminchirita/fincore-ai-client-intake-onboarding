# Security policy

This repository is a fictional portfolio demonstration and must not receive real personal, payroll, tax, banking or confidential client data.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials or sensitive data. Contact the repository owner privately with:

- affected component and version;
- reproduction steps using synthetic data;
- expected and observed impact;
- suggested mitigation, if available.

## Supported scope

Only the latest commit on the default branch is supported. The local Docker configuration prioritizes demonstration usability and is not a production security baseline.

## Production warning

Before processing real data, implement TLS, SSO/MFA, least-privilege database roles, private malware-scanned storage, managed secrets, pinned image digests, centralized audit logging, backups with restore tests, rate limiting and jurisdiction-specific privacy/compliance review.
